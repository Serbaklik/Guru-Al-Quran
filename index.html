Aplikasi tidak bisa dimuat dalam iframe

Jika halaman di atas kosong, buka aplikasi langsung dengan klik link berikut:

  • Buka Aplikasi (Apps Script)
  • Halaman GitHub Pages

Catatan teknis: jika Apps Script tidak mau terbuka di iframe, kemungkinan pengaturan web app belum mengizinkan embedding atau belum di-deploy untuk "Anyone".
